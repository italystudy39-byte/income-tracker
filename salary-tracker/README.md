# Учёт доходов и расходов

Одностраничное приложение без сборки: откройте `index.html` в браузере.

- Валюта: узбекский сум (UZS), суммы целые, формат `1 250 000 сум`.
- Хранение: `localStorage`, ключ `salaryTracker.v1`.
- CRUD записей: добавление, просмотр в журнале (фильтры по типу, категории, поиск), изменение, удаление с подтверждением.
- CRUD категорий: добавление, переименование (обновляет записи), удаление (только неиспользуемых).
- Дашборд: итоги за выбранный месяц или всё время, столбчатый график за 6 месяцев, кольцевая диаграмма по категориям.
- Графики: Chart.js 4.4.1 с cdnjs, объём даёт собственные плагины `bar3d` и `pie3d` (грани столбцов и толщина кольца).
- Тема: переключатель «Авто / Светлая / Тёмная», выбор хранится в `localStorage` под ключом `salaryTracker.theme`.
- При первом запуске загружаются примерные записи (помечены `demo: true`), кнопка «Удалить примеры» убирает только их.

Накопления (вкладка «Накопления», ссылка с `#savings`):
- Копилки: создание, переименование и цель, удаление вместе с историей; прогресс к цели.
- Операции «Отложить / Снять»: добавление, изменение, удаление; снять больше баланса копилки нельзя.
- Автоматическое откладывание: N% каждого нового дохода уходит в выбранную копилку. Такая операция связана с доходом (`sourceEntryId`) и пересчитывается или удаляется вместе с ним.
- На дашборде «Свободный остаток» = доход − расходы − отложенное.

Модель данных:

```json
{
  "entries": [{ "id": "…", "type": "income|expense", "amount": 1250000, "category": "Продукты", "date": "2026-10-15", "note": "", "createdAt": 0 }],
  "categories": { "income": ["Зарплата", "…"], "expense": ["Продукты", "…"] },
  "savings": {
    "goals": [{ "id": "…", "name": "Подушка безопасности", "target": 30000000 }],
    "ops": [{ "id": "…", "type": "deposit|withdraw", "amount": 500000, "goalId": "…", "date": "2026-10-15", "note": "", "sourceEntryId": "…", "percent": 10 }],
    "rule": { "enabled": true, "percent": 10, "goalId": "…" }
  }
}
```
