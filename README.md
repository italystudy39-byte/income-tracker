# Income Tracker — Road to 120 Million UZS

Личный трекер доходов с целью **120 000 000 сум** к **1 января 2028**.
Старт — 12 октября 2026, начальный баланс — 0 сум, период — 446 дней.

## Запуск

Сервер не нужен. Откройте `index.html` в браузере (Chrome, Edge, Firefox, Safari).
Для графиков нужен интернет при первой загрузке страницы: Chart.js и шрифт Manrope подключаются с CDN.
Без интернета всё, кроме графиков, продолжит работать.

## Структура

```text
income-tracker/
├── index.html   — разметка всех разделов и модальных окон
├── style.css    — тема Premium Finance Dashboard, адаптивная вёрстка

├── widget-start.bat   — Windows: открыть виджет маленьким окном
├── widget-install.bat — Windows: ярлык на рабочем столе + автозапуск

```

## Возможности (этап 1)

- **Главная** — заработано / цель, процент, остаток, дни до дедлайна, нужный доход в день и в месяц, анимированная шкала прогресса, последние поступления, контрольные точки.
- **Доходы** — история в таблице, поиск по названию и комментарию, фильтр по категории, сортировка по дате и сумме, редактирование, удаление с подтверждением.
- **Аналитика** (Chart.js) — рост накопленного дохода с линией плана, доходы по месяцам со средним планом, распределение по категориям.
- **Календарь** — октябрь 2026 — январь 2028, суммы по дням, подсветка дней с поступлениями, операции выбранного дня, итог месяца, добавление дохода на выбранную дату.
- **Цели** — этапы 10 / 25 / 50 / 75 / 100 / 120 млн со статусами «Достигнуто» / «Не достигнуто» и уведомлением при достижении.
- **Настройки** — параметры цели, экспорт в JSON, импорт резервной копии, полная очистка с подтверждением словом «УДАЛИТЬ».

## Возможности (этап 2)

- **Главная** — темп относительно плана (опережение или отставание), прогноз суммы на 01.01.2028 и ожидаемая дата цели, план и факт текущего месяца с нужным доходом в день до конца месяца.
- **Аналитика → Расширенная статистика** — средний доход в день и в месяц, средний чек, крупнейшее поступление, лучший день и месяц, последние 30 дней, сравнение с прошлым месяцем, дни с поступлениями, главный источник.
- **Аналитика → Финансовый прогноз** — прогноз по среднему темпу и по темпу 30 дней, дата достижения цели, отклонение от плана, график факт / план / прогноз.
- **Аналитика** — таблица категорий (операции, сумма, доля) и доход по дням недели.
- **Цели → План по месяцам** — равномерный план по дням периода (ровно 120 000 000 сум), ручное редактирование любого месяца, «Пересчитать план» (распределяет остаток цели по текущему и будущим месяцам), «Сбросить».
- **Цели → Калькулятор цели** — при заданном доходе в месяц показывает дату достижения цели и запас или опоздание относительно дедлайна.
- **Цели → Достижения** — 13 достижений, которые открываются по реальным данным, с уведомлением и датой получения. При удалении операций достижение снова закрывается, если условие перестало выполняться.
- **Настройки** — экспорт в CSV для Excel (разделитель `;`, UTF-8 с BOM).
- Горячие клавиши: `N` — добавить доход, `1`–`6` — разделы, `Esc` — закрыть окно.

Данные этапа 2 (планы, достижения) хранятся в `ext` и попадают в JSON-копию.

## Мини-окно на рабочем столе

- Кнопка **«Мини-окно»** вверху (или Настройки → «Мини-окно на рабочем столе»).
- **Chrome / Edge 116+**: открывается маленькое окно Picture-in-Picture поверх всех программ. Оно обновляется сразу после каждого изменения. Вкладку трекера можно свернуть, но не закрывать.
- **Другие браузеры или отдельное окно**: `widget.html` — компактная страница только для чтения. Она берёт данные из LocalStorage того же браузера и обновляется сама (событие `storage` + раз в 30 секунд). Откройте её в том же браузере и из той же папки, что и `index.html`.

### Windows: виджет на рабочем столе

1. Скачайте репозиторий (Code → Download ZIP) и распакуйте его в постоянную папку, например `Документы\income-tracker`.
2. Дважды щёлкните `widget-install.bat`. Он создаст на рабочем столе ярлык «Road to 120M», добавит виджет в автозапуск и откроет его маленьким окном Chrome (если Chrome нет — Edge).
3. Трекер (`index.html`) открывайте в том же браузере: виджет показывает данные этого браузера.

Чтобы отключить автозапуск, удалите «Road to 120M» из папки `shell:startup`.

### Windows: виджет прямо на обоях (Rainmeter)

1. Установите бесплатную программу Rainmeter с сайта rainmeter.net.
2. Дважды щёлкните `rainmeter/Road120M.rmskin` → Install. Виджет появится на рабочем столе, под всеми окнами.
3. Откройте трекер (`index.html`) в Chrome или Edge → Настройки → «Виджет на рабочем столе» → «Подключить папку виджета» и выберите `Документы\Rainmeter\Skins\Road120M`.

После этого трекер при каждом изменении записывает `progress.txt` в папку виджета, а виджет перечитывает его каждые 10 секунд. Дни до дедлайна и «нужно в день» виджет считает сам по часам компьютера. После перезапуска браузера трекер может один раз попросить «Разрешить» запись (жёлтая плашка вверху). Двойной клик по виджету открывает трекер, перетаскивается мышью.

## Хранение данных

- LocalStorage, ключ `incomeTracker.v1`, автоматическое сохранение при каждом изменении.
- Зеркальная копия последнего сохранения в `incomeTracker.v1.backup`. Если основной ключ повреждён, приложение откладывает его в `incomeTracker.v1.corrupt.<время>` и восстанавливает данные из копии, а не обнуляет баланс.
- Все суммы — целые сумы (`Number.isSafeInteger`), проценты считаются в базисных пунктах, поэтому ошибок округления нет.
- Даты хранятся как `YYYY-MM-DD` и считаются в UTC-днях, без сдвигов часовых поясов.
- Изменения в одной вкладке подхватываются в других.

Данные живут только в этом браузере. Регулярно делайте экспорт в JSON.

### Формат резервной копии

```json
{
  "app": "income-tracker",
  "version": 1,
  "incomes": [
    { "id": "…", "amount": 2500000, "date": "2026-10-20", "category": "web",
      "source": "Название проекта", "comment": "", "createdAt": "…", "updatedAt": null }
  ],
  "milestonesReached": [],
  "ext": {}
}
```

Категории: `freelance`, `web`, `ai`, `telegram`, `youtube`, `saas`, `other`.

## Расчёты

- Дней до дедлайна = 01.01.2028 − сегодня (12.10.2026 → 446).
- Нужно в день = ⌈остаток / дней до дедлайна⌉.
- Нужно в месяц = ⌈остаток × 30,4375 / дней до дедлайна⌉ (средний месяц = 365,25 / 12 дня).

## Расширение

Ядро предоставляет точки расширения, чтобы следующие этапы не переписывали существующий код:

- `App.onRender(fn)` — функция `fn(stats)` вызывается при каждом обновлении данных.
- `App.chartUpdaters.push(fn)` — дополнительные графики.
- `App.state.ext` — место для данных расширений (сохраняется, экспортируется, переживает очистку операций).
- Контейнеры `#dashboardExtra`, `#analyticsExtra`, `#goalsExtra`, `#settingsExtra` в разметке.
- `window.initStage2(App)` вызывается при старте, если определена.
